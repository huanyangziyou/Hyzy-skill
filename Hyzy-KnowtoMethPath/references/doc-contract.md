# 方法路径文档契约

> 本文件是 `Hyzy-KnowtoMethPath` 的输出标准。目标库若有 `_规范-*.md`，以库规范优先，本契约作兜底。

## 1. 文件命名与位置

```
<原文档所在目录>/
├── <原知识文档>.md
└── method path/                          ← 缺失则创建
    ├── <主题>求解标准化流程.md            ← 主交付物
    └── _verify-log.md                    ← 案例验算记录
```

- 目录名固定为 `method path`（带空格）。若目标库已存在 `method_path` 或 `<领域>-method_path`，**跟库走**，不新建第二种。
- 主题名取"对象 + 动作 + 标准化流程"，如 `复变函数积分求解标准化流程`、`矩阵对角化求解标准化流程`。
- 若原文档里已经预留了 wikilink（如 `[[XXX求解标准化流程]]`），**文件名必须严格等于该链接文本**，否则链接失效。

## 2. 章节骨架

```
# <主题>求解标准化流程

> 引用块：真正的分岔点是什么（≤3 行，不超过 2 个判据）
> 第二段：本文与原文档的关系 + 编号顺序 ≠ 使用顺序的说明

## 1. 路径选择图               ← 内联 SVG，唯一一处图
## 2. N 条路径总览             ← 总表
## 3. 判定链速查               ← 判定链表
## 4. 路径 A · <名称>
### A1 <子类型>
### A2 <子类型>
## 5. 路径 B · <名称>
…
## N-2. 易错判定对照           ← 表
## N-1. 小结                   ← 表
```

硬性要求：

- H1 有且只有一个。
- `## N.` 编号**从 1 连续到末节**，不跳号、不重号。脚本会查。
- 路径章节标题统一格式 `## <编号>. 路径 <字母> · <名称>`，字母用 A、B、C…（不用 1、2、3，避免与章节号混淆）。
- 子类型标题 `### A1 <子类型名>`，字母+数字与总览表"算例"列**逐一对应**。

## 3. 三张必备表

### 3.1 路径总览表

| 列 | 必填 | 内容要求 |
|---|:--:|---|
| 路径 | ✓ | `**A**` 加粗字母 |
| 触发条件 | ✓ | 判据链上抵达该路径的全部条件的合取 |
| 核心公式 | ✓ | 一条，用 `$$` 或行内 `$` |
| 建议顺序 | ✓ | 整数，按省力程度排（1 = 最先试） |
| 算例 | ✓ | `A1 / A2` 形式，列出该路径所有子类型 |

> 「建议顺序」列是本类文档与普通教材的分水岭。没有它，读者面对七条路径仍然不知道先试哪条。

### 3.2 判定链速查表

| 步 | 判据 | 成立 → | 不成立 → |
|:--:|---|---|---|

- 「成立/不成立」填的是**下一步编号**或**路径字母**，不能填描述性文字。
- 表后紧跟一行 `>` 引用块，点出这条链上最容易被走错的一到两条边。

### 3.3 易错判定对照表

| 情形 | 错误做法 | 正确做法 | 对应路径 |
|---|---|---|---|

- "情形"必须是**具体可触发**的，如"分母有根但根在 C 外"，不能写"理解不深"。
- 每行都要能指回一条路径。

## 4. 案例模板

每个子类型一个案例，固定三拍：

```markdown
**算例**：<题目 + 全部已知条件，独立可读，不能写"同上">

**为什么走这条**：<一句判据。这一段强制存在，防止读者只记公式不记条件>

$$
<推导，每步一个 $$ 块，与源文档风格一致>
$$

$$
\boxed{<结果>}
$$
```

要求：

- 案例之间**不重复同一道题的不同算法**，除非目的就是做方法互检（此时必须在案例后注明"与 X 互为验证"）。
- 结果一律 `\boxed{}`。脚本会统计 boxed 数量与案例数是否匹配。
- 推导中间步骤不做跳跃，但也不写"解："这类口头引导。

## 5. 风格对齐（继承源文档）

动笔前读同目录 1–2 篇既有笔记，对齐以下项：

| 项 | 检查点 |
|---|---|
| 章节编号 | `## 1.` 还是 `## 一、`，与同目录一致 |
| 公式块 | `$$` 独占行，块间空一行 |
| 多行推导 | 每步单独 `$$` 块，还是 `\begin{aligned}` |
| 强调 | `**粗体**` 用于判据关键词 |
| 间距控制 | 源文档若用 `~~~~` 调展示式内间距，沿用 |
| 分节线 | 用 `---` 还是靠标题层级 |
