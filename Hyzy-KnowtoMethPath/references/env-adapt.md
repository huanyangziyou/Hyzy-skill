# 环境自适应（KnowtoMethPath）

> **何时读**：Stage 0 契约勘察之前必读；要跑 `scripts/verify_methpath.py` 或写 SVG 之前复核第二节。

本 skill **不解析任何盘符路径**——产物目录由用户给的原文档位置推导，不是本机固定值。因此没有需要问的绝对路径，也没有需要探测的虚拟环境。下面只列真正会随宿主变化的三项。

## 一、三个会变的东西

| 项 | 谁决定 | 怎么定 |
|---|---|---|
| `<原文档所在目录>` | 用户给的原文档路径 | 取该文件的父目录；产物落 `<原文档所在目录>/method path/`，目录不存在才创建。**不要拿当前工作目录顶替** |
| `<PY>` | 环境探测 | 只需标准库（`cmath`、`xml.etree`、内置 `re`），任意 Python 3 即可。用于算例数值反算与 `verify_methpath.py` |
| `<SKILL_DIR>` | 本文件位置 | 由 `SKILL.md` 所在目录推导，用来定位 `scripts/verify_methpath.py` |

## 二、宿主渲染约束（不是路径，但会换）

- SVG **必须用 680px 宽的 `viewBox`**（宿主对非 680 宽会拒绝渲染）。这是最高频返工原因，与机器无关但与宿主有关；换宿主时先出一张最小图试渲染。
- 配色与坐标公式见 `svg-spec.md`；溢出/越界防护在写图**之前**读，不是画完再调。
- 若宿主不支持 SVG 内联渲染，如实标注「未做渲染核对」，不得假称已核对。

## 三、硬门（违反即失败）

- **同目录已有同名文档 → 停下问**，绝不覆盖（覆盖风险见 `SKILL.md`「不能做的事」）。
- 原文档路径没给、或给的是目录而不是文件 → 问清楚再动；不猜一个工程目录写进去。
- 解析结果**不写回本文件**——保持占位符，换机器仍自适应。
- 产物目录属于用户文档区，**只新建 `method path/` 及其内部文件**；不移动、不重命名、不删除该目录下任何既有文件。
- 算例必须**实际跑数值反算**（`cmath`），不能只写推导过程；校验器 `verify_methpath.py` 末轮跑一次，问题合并成一轮修正。

## 四、本机默认值

无。本 skill 没有需要固定下来的本机路径或解释器版本——`cmath` 属标准库，任意 Python 3 均可。这一节保持为空是**有意**的：不要为了"规格齐"编一个 venv 路径进去。
