# 踩坑清单（KnowtoMethPath）

> 全部为实战中真实发生过的问题，按发生频率排序。

## 1. 手写 URL 编码出错（高频）

`Pasted image 20260827113936.png` 转引用时手写成 `Pasted%20image%20260827113936.png`，第二个 `%20` 把年份 `2026` 的 `20` 吃掉了，解码成 `Pasted image 260827113936.png`，图片解析不到。

**修法**：任何 URL 编码一律 `urllib.parse.quote()` 生成，不手写 `%20`。更优解是把含空格的文件名改 kebab-case，引用里就不需要编码。

## 2. SVG 坐标凭感觉写（高频）

不填坐标规划表直接写标签，结果：文字右边被切、连线穿过其他框、箭头埋进框里。

**修法**：严格执行 `svg-spec.md` 第 2 节的坐标规划表 + 第 6 节三查。

## 3. 表格里的裸竖线（高频）

在 markdown 表格单元格里写 `$|z|=2$`，`|` 被解析成列分隔符，整行错位。

**修法**：表格内一律 `$\lvert z\rvert=2$`；或改用 `$\vert z \vert=2$`。正文（非表格）不受影响。

## 4. 嵌套 `\begin{cases}`（中频）

小结里用嵌套 cases + `\\[4pt]` 间距参数，KaTeX 支持不稳，渲染成乱码或直接失败。

**修法**：改用表格承载多分支判据。表格本来也更符合"表格式概括"的要求。

## 5. 案例只推不验（中频）

推导看着对，但系数错了（如把 `1/(2i)` 写成 `1/2i` 后约掉 `i` 的符号）。肉眼极难发现。

**修法**：Stage 5 强制数值反算。只要有一条独立途径能给出数值/符号对照，就一定要跑。

## 6. 指向不存在文件的图片引用（中频）

文档第 1 节写 `![](决策图.svg)`，但实际用的是内联 SVG，该行成了死链。

**修法**：内联 SVG 就不要再写图片引用。交付前跑一遍链接校验。

## 7. 路径切分粒度过细（中频）

把"参数化直线段"和"参数化圆周"当成两条独立路径，导致路径数虚高、决策图卡片挤不下。

**修法**：路径 = 判据链的一条终点边。同一判据下的不同参数化形式是**子类型**（A1/A2/A3），不是并列路径。

## 8. 编号三处不一致（中频）

总览表写"算例 A1/A2/A3"，正文只写了 A1、A2；或 SVG 卡片写"G"，正文标题写"路径 H"。

**修法**：编号定稿后，用 `verify_methpath.py` 自动核对总览表、子标题、案例标记三处。

## 9. 暗色主题下整图看不见（低频）

SVG 只写深色文字没加深色底，浅色主题正常，切到暗色全隐形。

**修法**：画布加 `fill="#FCFCFB"` 之类浅底 rect 作为首元素。

## 10. 章节号跳号（低频）

删掉某节后忘了重排 `## N.`，出现 1,2,3,5,6。

**修法**：脚本查编号连续性；改稿后必跑。

## 11. 误以为 figure 会自己编号（低频）

以为 `## 4. 路径 A` 里的字母 A 会自动跟章节号联动。不会。三处都得手动改，改完必须跑校验。

## 交付前自检（按顺序）

1. `$$` 数是否偶数 → 脚本 D3
2. `\begin{}` / `\end{}` 是否配对 → 脚本 D8
3. 表格列数是否各行一致 → 脚本 D4
4. 表格内是否有裸 `|` → 脚本 D5
5. 总览表字母 / 子标题 / 案例标记三处是否一致 → 脚本 D6
6. `## N.` 是否连续 → 脚本 D7
7. SVG 每个框的文字是否溢出 → 脚本 W1
8. 每个案例是否都有 `\boxed` → 脚本 W4
9. 案例是否全部验算 → 人工 + `_verify-log.md`
10. 是否动了原文档 → `git status` 或文件时间戳核对
