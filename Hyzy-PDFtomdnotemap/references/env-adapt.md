# 环境自适应协议（PDFtomdnotemap）

本 skill 不绑定任何机器。所有路径都是**占位符**：占位符原样出现，就意味着「本机未配置」，而不是「路径字面值」。

## 一、五个占位符与解析责任

| 占位 | 含义 | 本 skill 的要求 | 谁定 |
|---|---|---|---|
| `<SKILL_DIR>` | 本 skill 所在目录 | 直接推导，不问人 | 自动 |
| `<PY>` | 跑五个脚本的 Python 3 | **只需标准库**（脚本 import 全是 stdlib） | 自动探测 |
| `<VENV>` | 装了 `pymupdf4llm` 的 Python | **仅 Stage 1 转换需要**，通过 `--py` 传给 `convert_pdf2md.py` | 探测，缺失才问 |
| `<素材目录>` | 待入库的 PDF 所在目录 | 用户指定 | **必须问** |
| `<库根>` | 目标概念笔记库根 | 用户指定；其下应有域目录与总索引 | **必须问** |

> 关键区分：`<PY>` 与 `<VENV>` 不是一个东西。五个脚本本身只吃标准库，随便一个 python3 就能跑；只有真正解析 PDF 的那一步需要 `pymupdf4llm`，它由 `convert_pdf2md.py --py` 单独指定。把两者混为一谈，会导致「跑个核验也要先装 PDF 库」的无谓门槛。

## 二、三步处理，不得跳步

1. **先探测（只读，不问人）**
   ```bash
   # <SKILL_DIR>
   cd "<本 SKILL.md 所在目录>" && pwd
   # <PY>：逐个试，取第一个可用的
   python3 -c "import sys;print(sys.executable)" || python -c "import sys;print(sys.executable)" || py -3 -c "import sys;print(sys.executable)"
   # <VENV>：确认某个解释器带 pymupdf4llm
   "<候选解释器>" -c "import pymupdf4llm;print('ok')"
   ```
   `<VENV>` 候选顺序（与 `convert_pdf2md.py` 的 `resolve_py()` **逐项一致**）：`HYZY_PDF_PY` → `HYZY_VENV_PY` → 当前解释器 `sys.executable` → `$USERPROFILE/.workbuddy/binaries/python/envs/*/{Scripts/python.exe,Scripts/python,bin/python}` → `PATH` 上的 `python3`/`python`。每个候选都要 `import pymupdf4llm` 通过才算命中；探不到时脚本会打印带问法的提示并退出。

2. **唯一结果 → 直接用**，并在第一次回复里写明「已将 `<X>` 解析为 …」。

3. **探测不到 / 多个候选 / 属于用户偏好 → 问，且只问一个**
   - `<素材目录>` 与 `<库根>`：**用户没给过才问**，不猜（猜错会读错书、写错库）。**本轮已给过就直接用**，只在首次回复复述「素材区 = …、库根 = …」，不重复确认。
   - 只有用户给了一个路径却分不清角色时，才补问一次：「`<路径>` 是素材区（放 PDF）还是概念笔记库（放成品）？另一个在哪？」
   - `<VENV>`：**只在真正要跑 Stage 1 时才探测/询问**——单本书、走轻流程时根本用不到，别提前问。缺失时问：「Stage 1 需要 `pymupdf4llm`。你已有吗？给路径；没有我可以装到 `<SKILL_DIR>/.venv`，要装吗？」

## 三、硬门（违反即失败）

- 占位符未解析就执行命令 —— 会把模板路径当真实路径。
- 拿 `/tmp`、当前目录、或文档里的示例路径当默认值 —— 禁止。
- 在 `<库根>` 未知的情况下先跑 Stage 1 转换 —— 禁止。转换产物要按库的素材约定落盘，库根不明就无从对齐。
- 把解析结果写回本 skill 的任何文件 —— 禁止。占位符必须原样保留，否则换机器又要人工改一遍。
- 重复追问用户**已经明确给出**的信息 —— 禁止。一次问清，之后直接干活；反复确认不是严谨。
- 在**还用不到**某占位符时提前问它（如还没到 Stage 1 就问 venv）—— 禁止。
- 拿不准却不问 —— 禁止。

## 四、问法模板

```
开始前需要两个位置：
1) <素材目录>：放这批 PDF 的目录
2) <库根>：概念笔记库的根目录（其下应有域目录与总索引）
给两个目录即可；如果你只想先看方案不落盘，说「只出方案」。
```

一次问完，不拆多轮。用户已在前文给过其中一个时，只问缺的那个。
