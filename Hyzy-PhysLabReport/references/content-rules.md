# 内容口径：字数、结构与"该不该写"

> 格式合规管不住冗余。本文件是 3 轮定稿复盘（电容 / 霍尔 / 电子束）沉淀出的内容判据，**优先于"看起来完整"**。

## 一、字数预算

| 项 | 上限 | 落点 | 说明 |
|---|---|---|---|
| 总汉字 | 专用约束定（默认 600） | 500–560 | 超限是本类任务的最高频失败点 |
| 正文（一、二） | — | 240–300 | 事实与结果，几乎稳定 |
| 课后习题 | — | 220–320 | 浮动最大，压字数先压这里 |
| 单题答案 | 160 字 | 80–130 | 含符号与数字；不含题干 |

**删的顺序（固定，不许乱来）**：习题答案 → 中间推导 → 分条 → 正文事实。
**不许删**：终值及其单位、误差/偏差、教师点名要的结论句。

## 二、三段式骨架（唯一允许）

```
物理实验报告            [22pt 粗 居中]
实验名称： …             [12pt 粗，下划线填空]
班级/姓名/座位号     [12pt 粗，下划线填空]
一、实验数据记录         [18pt 粗]  ← 只放原始数据图，不放曲线图
二、数据处理             [18pt 粗]
  1、测量表格数据        [15pt 粗]  ← 全部表格归此节
  2、测量数据计算        [15pt 粗]
     (1)…              [14pt 粗]  ← 图 + 公式 + 结论句
     (2)…
     (3)…
三、课后习题             [18pt 粗]
  1、原题               [12pt 粗]
     答案（首行缩进 2 字符）
```

**铁律**：不设「实验原理」「误差来源分析」「注：」三节；表格与曲线图不得混放；每节标题下不写导语式散文。

## 三、内容判断四条（每写一句就过一遍）

1. **删掉这段，读者会缺什么信息？** 答不出具体信息 → 删。
2. **这句话「二」里是不是刚说过？** 是 → 习题/结论里删（最常犯）。
3. **这是原理还是结果？** 离开本次数据仍成立的公式 → 属"实验原理"，本报告不写；含本次拟合系数/残差的 → 才写。
4. **归因可观测吗？** 写"因为第二次测前经过消磁"，不写"源于剩磁状态差异"。

## 四、结构化写作范式（已定稿验证）

| 场景 | 范式 |
|---|---|
| 拟合结果 | 提示语「由拟合直线：」→ 两条显示公式（各条件一条）→ 空行 |
| 汇总对比 | 「根据物理公式推导，有：」→ 关系式（**行内公式即可**）+ 理论比值 → 表 → 逐判断分段写对照 |
| 误差 | 「由误差公式：」→ 单个根式 → 「则相对误差为：」→ `E=σ(x)/x`；符号统一 σ |
| 习题答案 | 结论先行 → 一句机理 →（可选）一句边界说明；不复述中间结果 |

## 五、课后习题写法

- 题量 2–3，**按原题逐字照抄**（含原题的 `?` 与 `。` 混用，不要"统一标点"）。
- 每题 1 段、不分条、不写「答：」、不写总述句。
- 三禁：**方法命名标签**（"采用逐档换向退磁法："）、**后果推演**（"否则会…"）、**权衡收尾**（"需在…之间折中"）。
- 只用题目问的东西；题问"关系"，答案给关系 + 一句机理，**不代公式、不代数值**（除最终比值）。
- 每题写完自查：这段内容能不能在「二」里原样找到？能找到 → 删。

## 六、字符间距（硬规则）

- 汉字 ↔ 字母 / 数字：**不加空格**。`X轴电偏转`、`表1：`、`图2：曲线`、`约3.6 m`。
- 允许保留：**数值与单位之间**（`0.585 mm/V`、`3×10⁻⁵ T`）、**全角填空空格**（`班级：　XXXXXXX`）、公式内部排距。
- 模板明确要求加空格时**先申请**，不默认执行。
- 自检：`grep -P '[\x{4e00}-\x{9fff}][ \t]+[0-9A-Za-z]|[0-9A-Za-z][ \t]+[\x{4e00}-\x{9fff}]'` 应为 0（排除全角）。

## 七、符号与数值

| 项 | 规定 |
|---|---|
| 符号来源 | **以原始数据表与习题为准**（本次教训：原始表写 `U₂`，我写成 `V₂`，习题直接对不上） |
| 负号 | `−`(U+2212)，不用连字符 `-` |
| 有效位 | 与原始读数一致；拟合斜率比原始多一位；比值统一 3 位（1.18 / 1.23） |
| 单位 | 表头写 `D/(mm)` 形式；正文数值带单位；公式里单位用正体 `\mathrm{mm/V}` |
| 一致性 | **图内标注 = 表格 = 显示公式 = 正文**，四处同一个数（0.692 还是 0.693 必须统一，本次踩过） |

## 八、可迁移规则（按来源加前缀，避免跨定稿编号撞车）

> 编号规则：`EB` = 电子束定稿，`GS` = 光栅定稿。**不同来源的规则编号不共用**，回灌时写「GS3→规范§11.4」这类带前缀的映射，不写裸「R3」。

### 8.1 电子束定稿 EB1–EB7

| # | 规则 |
|---|---|
| EB1 | 汇总型表格前先给理论关系（行内公式即可）+ 理论值，再上表，最后对照 |
| EB2 | 结论段按「判断单元」分段：一段 = 一个对象的一个判断 |
| EB3 | 习题不复述「二」的中间结果 |
| EB4 | 汉字与字母/数字不加空格 |
| EB5 | 表标题不自造后缀（「汇总」「一览」「统计」都不写） |
| EB6 | `取 A 估算`用于人为选定参数，`由 A 估算`用于由已知量导出 |
| EB7 | 实测与理论的对照**必须带容差限定**：偏差 >2% 写「在实验误差范围内相符」，不写「相符」；≤0.5% 才可直接说相符 |
