# P0–P6 阶段细则

> 主流程见 `SKILL.md` §四。本文件补每阶段的动作清单、产出格式与「不过门禁」的判定。

## P0 摄取

**动作顺序**（有依赖，不能跳）：
1. `ls <EXP_DIR>` → 按内容认材料（见 SKILL §三 表）。目录名历年不一致，只认内容特征。
2. 读 `任务说明.txt` → 拿到本次的步数（有时是 5 步，有时 4 步）。
3. 读 `实验报告内容要求.txt` → **抄下三件事**：要几张表、要几张图（含"哪些电压/电流条件"）、课后习题原题（逐字，不改标点）。
4. 讲义全页逐张看，只提取：原理式（含符号定义）、实验参数（d、L、l、匝数…）、读数方法。
5. 数据处理办法（PPT 截图）：误差/不确定度用哪套口径、结果保留几位。

**判方向**：原始数据照片大多横拍。用 PIL 读入后先看一版，若文字竖排 → `transpose(ROTATE_90)`；仍不对 → `ROTATE_270`。**判据是表头文字能正向读**，不是"看起来差不多"。

**转录规矩**：
- 一格一格读，读完整表立刻回读一遍，比对关键列（正反读数应对称）。
- 负号用 `−`(U+2212) 统一；`0` 不写 `0.0`（除非全表都是 `x.0` 格式，从原始表）。
- **每一次"猜"都要登记**：日期、遮挡格坐标、辨认依据（如"按 8 的笔画断开处判为 8.0"）。

**门禁**：能不看材料复述出「N 张表 / M 张图 / K 道题 / 用什么误差口径」。

## P1 数据

**Excel 规格**（用户会直接看，别做丑）：
- 一表一 worksheet，名称 `表1-X轴电偏转` 这类"编号+主题"。
- 横向（列=测量点，行=物理量）或纵向（行=测量点）**跟原始表一致**，便于对照；页面设置 `fitToPage`。
- 数字格式与原始表同位数；标题行加粗、冻结首行。
- 末尾加 `计算与拟合` sheet：斜率/截距/r/公式（写清拟合的是哪两个量、谁当自变量）。

**自校验（必须跑，报给用户看）**：
| 检查 | 判据 |
|---|---|
| 正反对称 | 电学类 `|x(i)|−|x(n−i)| ≤ 1.0` 单位；磁学类 ≤ 6（读数更粗）。**按表给容差** |
| 单调性 | 同一列随自变量单调变化，无跳变（跳变必是转录错） |
| 量级 | 结果与讲义公式估算差 ≤ 一个数量级，否则先怀疑单位（mm vs cm、mA vs A） |
| 拟合 | `r ≥ 0.999` 才算干净；不达标先查数据点，不要硬拟合 |

**门禁**：用户回"数据正确"。此前不做任何图、不写任何正文。

## P2 专用约束与任务规划

十节固定结构（缺节会被后续阶段反咬）：

1. **基本信息冻结**：实验名、日期、班级/姓名/座位号、教师要求原文摘要。
2. **教师要求 → 落点表**：每条要求映射到报告某一节某一图/表。
3. **偏离登记**：偏离通用规范的每一项 + 依据（规范条款号 / 教师要求 / 上次复盘）。
4. **数据冻结**：三张表的全部数值 + 九（或 N）条拟合结果（斜率/截距/r）。
5. **骨架 + 字数预算**：逐节写预计汉字数，合计 ≤ 上限；给"正文 X / 习题 Y"的分配。
6. **公式清单**：编号、内容、字号、行内/显示、预期 `oMathPara` 计数。
7. **表格规格**：张数、行列、列宽、表头写法、标题文字。
8. **绘图规格**：张数、每张画哪几条线、坐标范围/刻度、标注内容（数值必须与公式一致）。
9. **课后习题答案要点**：每题的"必须包含的 2–3 个要点"，不写整段答案。
10. **验收清单 + 任务规划**：P0–P6 状态表 + 构建脚本基线（用哪个历史脚本当底）。

**门禁**：偏离项逐条报批过。

## P3 图

见 `SKILL.md` §六 与 `scripts/plot_curves.py`。三个必查：
- 标注数值 = 正文数值（同一个舍入，同一个小数位）；
- 刻度落在整数/半整数，不用 `range(int(lo), hi, 6)` 这种拍脑袋步长；
- 拟合线不许出框（`ylim` 要比数据范围宽一档）。

## P4 构 docx

见 `references/ooxml-recipes.md`。**先跑通"骨架能生成 → 再填内容"**，别一口气写完再调。

段落顺序 = 专用约束的骨架顺序。每写完一节，跑一次自带统计（汉字/公式/表/图），偏离预算立即回改，不要留到最后。

## P5 验收

见 `references/verification.md`。**必做三件**：导 PDF、逐页 PNG 目视、跑自检脚本。
目视重点：图片是否被裁、公式是否跨行断裂、标题是否孤立页底、页面是否出现半页空白、表头是否溢出单元格。

## P6 定稿与复盘

用户手改后**不要重跑构建脚本**。流程：

1. 备份用户版：`<实验>报告（改前备份）.docx`（二次确认后再动）。
2. 段落级 diff：`<PY> <SKILL_DIR>/scripts/diff_docx.py A.docx B.docx`（或自写 difflib），按「加 / 删 / 拆段 / 去空格 / 改措辞」分类计数。
3. 写复盘 md，八节：
   - 一、结果对照（量化表：汉字/段落/公式/表/图/页数/空格违规）
   - 二、改动清单与判据（每条给"为什么这么改"）
   - 三、可迁移规则（R1…Rn，每条落到规范哪一节）
   - 四、我的判断失误（诚实清单，每条写"下次用什么检查动作拦住"）
   - 五、新硬知识（排版工程学，能复用）
   - 六、对通用规范的修订条目（要用户批准才写进规范）
   - 七、遗留问题（二选一 + 各自代价）
   - 八、复现性验证（可复制的命令）
4. **回灌**：规范 → 项目 `.workbuddy/memory/MEMORY.md` → 本 skill 的 `references/`。三处都写，缺一处下次还会犯。

> 判据：复盘的价值 = 下一次同类错误是否被**检查动作**拦住，而不是"下次注意"。
