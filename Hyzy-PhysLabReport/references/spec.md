# 物理实验报告 — 通用约束规范

> **地位**：本目录下所有同类物理实验报告的**唯一验收基准**。
> 逐条对应可验证的 XML 事实，不含主观描述；凡能写成参数的一律写参数，凡能写成数值的一律写数值。
> **适用范围**：本科生物理实验报告的「数据记录 + 数据处理 + 课后习题」三段式报告。
> **不适用**：课程论文、实验预习报告、包含完整「实验原理／仪器介绍」章节的长报告。
>
> 制定依据（全部实测，非推测）：
> - **电容最终版** = `电容与高电阻的测量实验\电容与高电阻的测量实验报告.docx`（85 分，最高分样本）

> - **参考格式模板** = `扭摆法实验\参考实验报告格式.docx`（下发样板，薄凸透镜报告）
> - **反例** = `扭摆法实验\扭摆法测切变模量实验报告 (AI生成）.docx`（不合格对照，用于校验禁止项）
> - **前序约束** = `扭摆法实验\扭摆法报告-格式与内容约束清单.md`（本文件是其上位替代，冲突时以本文件为准）

## 一、规范效力与冲突裁决顺序

遇到两份样本取值不一致时，按下列顺序裁决，**不得自由发挥**：

| 优先级 | 裁决依据 | 说明 |
|---|---|---|
| 1 | **用户当场指令** | 用户明确说「原来的那份字体格式是对的」这类话，直接覆盖本文件 |
| 2 | **电容最终版** | 唯一有明确分数（85 分）的成稿，优先于其他样本 |
| 3 | **扭摆标准版** | 用户逐字确认过，但页面设置漏设、含两处编号笔误 |
| 4 | **参考格式模板** | 只补前两者未覆盖的项，不覆盖前两者 |
| 5 | 反例（AI 稿） | **只作为禁止项来源**，任何取值都不得照抄 |

> **铁律**：样本之间冲突时，选「可以被 XML 验证的那个取值」，不选「看起来更合理的那个取值」。

### 6.2 三条铁律

1. **表格全部归「二、数据处理 › 1、测量表格数据」**。「一、实验数据记录」只放原始数据图——照片、手写表截图、仪器读数图，不放任何 `<w:tbl>`。
   - 反例：AI 稿把 4 张表全放在「一」下，错。
2. **表格顺序 = 测量发生的顺序**（时间序列 → 几何量 → 计算表 → 汇总表）。数量按实验实际需求，**2–4 张**。
3. **不设**「误差来源分析」小节，**不写**任何「注：……」说明段，**不设**独立的「实验原理」「仪器介绍」章节。

## 八、公式规范

### 8.1 技术规格（硬性）

1. 一律用 **OMML**（Office 原生公式）。不用截图、不用 Unicode 拼凑、不用文本上下标。
2. 显示公式必须落成 **`<m:oMathPara>`（显示型）**，且内部带居中：
   ```xml
   <m:oMathPara><m:oMathParaPr><m:jc m:val="center"/></m:oMathParaPr><m:oMath>…</m:oMath></m:oMathPara>
   ```
3. 公式 run 必须带 `Cambria Math`；`<m:ctrlPr>` 内也要带。
4. **`<m:t>` 文本内不得出现** `& \ { } ^ _` 及 `&amp;Delta;`／`&amp;pm;` 这类 HTML 实体（反例 15 处）。
   - **反斜杠零容忍**：`\lambda`、`\cos`、`\frac` 等 LaTeX 命令不得出现在 `<m:t>` 里——Word 会原样显示反斜杠，暴露生成来源。希腊字母与函数名直接用 Unicode（λ、cos、φ），分式按 §8.2 范例写斜杠式或用 OMML 分式构件。（2026-11-18 光栅定稿实测：习题 1 的 `dφ/dλ=k/(d cosφ)` 被写成 `dφ/d\lambda=k(d\cos φ)`，自检拦截。）
5. **禁止 `\sum`**——转换器会把基元与上下标写反（反例中 `e="i=1"`、`sub="5"`、`sup="∑"`，整体互换）。需要求和时直接写数值式。

### 8.2 写法范式

| 场景 | 写法 | 示例 |
|---|---|---|
| 纯符号关系式 | 单独一个显示公式段 | `J₁′=1/8·m(D₁²+D₂²)` |
| 符号式 + 数值结果 | **合并成一个显示公式段** | `G=128πl/(d⁴(T²−T₀²))·J₁′=75.802 GPa` |
| 数值代入过程 | 放进引导句，或直接省去 | 「代入表1中各次测量数据并取平均值：」 |
| 中间量 | 各给一个显示公式段 | `T′=T²−T₀²=9.838 s²` |
| 偏差传播 | 一个显示公式段，根式内逐项平方和 | `ΔT′=√((2TΔT)²+(2T₀ΔT₀)²)=0.0072 s²≈0.008 s²` |
| 最终结果 | 显示公式段，`(值±偏差)` ×10ⁿ **必带单位** | `G=(7.58±0.08)×10¹⁰ N/m²` |
| 行内公式 | **只用于给常量/已知量** | `m=0.48 kg`、`D₁=(100.00±0.02) mm` |

> 单行显示公式宽度 ≤ **14.65 cm**（A4 减去左右边距 3.175×2）。超过必须拆段，否则 Word 会自动折行，公式被劈成两半。

### 8.3 禁写公式清单

以下写法在合格样本中**一条都不存在**，出现即判不合格：

- ❌ 贝塞尔公式 `s=√[Σ(T₀ᵢ−T̄₀)²/(n−1)]`
- ❌ A 类 / B 类分项 `u_A=s/√n`、`u_B=0.001/√3`
- ❌ 合成式 `u(T₀)=√(u_A²+u_B²)=0.0049`
- ❌ 定理推导链 `T=2π√(J/F) ⇒ F=4π²J/T²`（原理已在教材里，报告不重推）
- ❌ 每个分项各写两三条公式（`ΔJ₁′`、`ΔJ₁′/J₁′`、`ΔT′`、`ΔT′/T′`、`ΔG/G` ×2）
- ❌ `T̄₀=(1/n)Σ…` 这类通式（直接给数值）

## 九、数值与误差写法（σ 单根式范式）

### 9.1 误差链路固定三段式

```
由误差公式：                        [12pt 提示语，单独一段]
σ(k)=√(Σ(lnQᵢ−b−ktᵢ)²/((n−2)·Σ(tᵢ−t̄)²))=1.17×10⁻⁴    [显示公式]
则相对误差为：                      [12pt 提示语]
E_R=σ(R_x)/R_x=σ(k)/|k|=1.01%       [显示公式]
则结果为：                          [12pt 提示语]
R_x=(86.0±0.9) MΩ                   [显示公式，带单位]
```

**三个不可省**：`由误差公式：` → 单个根式（分子为残差平方和，分母为自由度因子 × 自变量离差平方和） → `则相对误差为：`／`则结果为：`。

### 9.2 符号与形态：改前／最终对照（实测）

以电容报告第二轮修改为例（见 §9.5），用户指令「（2）中的误差计算方式参考（1）」后，三处同时改：

| 维度 | 改前（错） | 最终版（对） |
|---|---|---|
| 提示语 | `由斜率的标准偏差：` | **`由误差公式：`** |
| 公式形态 | 因式式：`u(k)=s_y/√(Σ(tᵢ−t̄)²)`（引入中间量 s_y） | **单根式**：`σ(k)=√(Σ(lnQᵢ−b−ktᵢ)²/((n−2)·Σ(tᵢ−t̄)²))` |
| 符号 | `u(k)`、`u(R_x)`、`E_R=u(R_x)/R_x` | **`σ(k)`、`σ(R_x)`、`E_R=σ(R_x)/R_x`** |
| 后续 | `E_R=u(R_x)/R_x=u(k)/|k|` | `E_R=σ(R_x)/R_x=σ(k)/|k|` |

> **符号纪律**：全文只用一套。`σ` 表示标准偏差型误差，`Δ` 表示不确定度绝对量（`ΔG`、`ΔT′`）；**禁止 `u`、`u_A`、`u_B`、`s_y` 混入**。同一份报告里 `σ` 与 `Δ` 可以并存（一个是相对量链路、一个是绝对量链路），但 `u` 一律不用。

### 9.3 有效位数与单位

| 规则 | 对 | 错 |
|---|---|---|
| 结果必带单位 | `(7.58±0.08)×10¹⁰ N/m²` | `7.58×10¹⁰` |
| 中间量给足位、结果按偏差修约 | `75.802 GPa` → `(7.58±0.08)×10¹⁰ N/m²` | 中间量就压成 3 位 |
| 偏差先给精值再约等 | `0.7632 GPa≈0.8 GPa` | 直接跳终值 |
| 偏差与主值末位对齐 | `(86.0±0.9) MΩ` | `(86.04±0.9) MΩ` |
| 同族量位数一致 | `J₁′=(1.4640±0.0004)×10⁻³ kg·m²` | `1.464×10⁻³`（少一位且无偏差） |
| 约等号用 `≈` | `0.0072 s²≈0.008 s²` | 省略约等 |

### 9.4 两种收尾，按实验要求选一种

| 收尾类型 | 适用 | 终值形态 |
|---|---|---|
| **相对误差收尾** | 实验要求「计算相对误差」（如电容与高电阻） | `E_R=σ(x)/x=1.01%` |
| **绝对不确定度收尾** | 实验要求「计算不确定度」（如扭摆测切变模量） | `ΔG=G·√[(Δl/l)²+(4Δd/d)²+(ΔJ₁′/J₁′)²+(ΔT′/T′)²]=0.7632 GPa≈0.8 GPa` |

> 一次计算内**不得混用**：写了 `ΔG` 就不要再补 `ΔG/G=1.0%` 作为终值；写了 `E_R` 就不要再补绝对量。

**第 1 题**：`在冲击法测量高阻实验中，标准电容的单位为μC，这个数量级是否会影响最终的测量结果？`

- 最终版（83 字）：

> 删掉的那一句（加粗部分）答的是「什么影响结果」，不是「这个数量级是否影响结果」——**答非所问的句子是首要删除对象**。

**第 2 题**：`放电法测量高阻阻值，最长放电时间的选择依据是什么？`

- 改前（约 145 字，从推导讲起）：
  > 放电过程满足 Q=Q0e−t/τ，作 lnQ~t 直线求斜率 k 即可得时间常数 τ=RxCN。最长放电时间应使电荷量降到初始值的四分之一左右……
- 最终版（结论先行）：
  > 放电法测量高阻时，最长放电时间的选择主要依据电容放电时间常数 τ=RC 与测量精度的关系：放电时间需足够长，使电压衰减到可准确测量的范围。若时间过短，电压变化太小、相对误差大；若时间过长，电压过小易受漏电、噪声，且测量效率低。因此应结合电容容量、电阻量级、电压表分辨率和允许误差，选择仪表最佳测量区间内的放电时间作为最长放电时间。

## 十一、文字语言规范

### 11.1 提示语必须极短（≤10 字，单行，12 pt）

合格样本的全部提示语清单：

`已知圆环质量`／`由转动惯量计算公式`／`代入…`／`计算得到：`／`其中：`／`由切变模量计算公式：`／`则由不确定度公式有：`／`则结果为：`／`由误差公式：`／`则相对误差为：`／`由放电公式：`／`由拟合斜率：`／`由标准电容：`／`以放电时间 t 为横坐标、lnQ 为纵坐标作图，并用最小二乘法拟合直线：`

> 最后一条是唯一允许的长提示语（作图说明），但也只有一句、不断句。

### 11.2 禁止的解释性散文

- ❌ 整节的方法学铺垫（「1、摆盘转动周期 T₀」含贝塞尔、3σ、A/B 类、折算说明）
- ❌ 「6、误差来源分析」整节（AI 稿 3 段 312 字）
- ❌ 数据来源的自辩句：「因该组后三次原始读数被遮挡，无法单独核算 A 类不确定度，故直接取……」
- ❌ 假设说明段：「此外，圆环质量 m 按给定值 480 g 处理、未计入其不确定度；……」
- ❌ 所有「注：……」段
- ❌ 解释性长句：数据能说明的事，不要再用文字复述一遍

### 11.3 字符间距：汉字与字母/数字之间不加空格（2026-11-11 新增，用户硬规则）

**硬规则**：汉字 ↔ 拉丁字母、汉字 ↔ 数字之间**一律不手打空格**。中西文之间的光学校正由 Word 的「自动调整中西文间距」完成，手打空格只会暴露排版来源（AI 生成特征）。

| 错误写法 | 正确写法 | 备注 |
|---|---|---|
| `X 轴电偏转` / `Y 轴方向` | `X轴电偏转` / `Y轴方向` | 表格行标签、表标题、小节标题全部适用 |
| `表 1：` / `图 2：` | `表1：` / `图2：` | Word 显示时自带的微量间隙不算空格 |
| `图1： 曲线` | `图1：曲线` | ❌ 冒号后不留空格 |
| `约 3.6 m` / `小于 1 mm` | `约3.6 m` / `小于1 mm` | 汉字与数字之间无空格 |
| `即 ε 随 U₂ 升高` | `即ε随U₂升高` | 汉字与公式/字母之间无空格 |

**允许保留空格的三种情形**（除此之外一律删除）：

| 情形 | 例 | 理由 |
|---|---|---|
| 数值与单位之间 | `0.585 mm/V`、`3×10⁻⁵ T` | SI 量值写法，不可黏连 |
| 填空用全角空格 `\u3000` | `班级：　XXXXXXX　姓名：` | 版式要求（下划线填空区）。**封面填空位只用全角空格**，禁用半角空格——半角空格既暴露生成来源，又触发本条硬规则（2026-11-18 光栅定稿实测） |
| 公式内部（OMML 排距） | `\quad`、`\;` | 由公式排版引擎决定，不手打空格对齐 |

> 若教师模板或作业要求明确要求中西文之间加空格，**先向用户申请、单独登记后再执行**；未获批准一律按无空格处理。

**自检**（排除全角空格后应为 0 命中）：
`grep -P '[\x{4e00}-\x{9fff}][ \t]+[0-9A-Za-z]|[0-9A-Za-z][ \t]+[\x{4e00}-\x{9fff}]'`

### 11.4 报告不写过程性注记（2026-11-18 新增，光栅定稿回灌）

**报告只呈现结论，不呈现修补过程。**以下内容一律不进正文：

| 类型 | 例子 | 合法去处 |
|---|---|---|
| 操作步骤复述 | 「望远镜对准谱线使叉丝与竖直直径重合，右游标记θ_A……」 | 讲义里已有，不进报告 |
| 数据辨认／涂改说明 | 「原图有涂改，辨认为252°25′」 | 专用约束的「偏离登记」 |
| 生成／交互痕迹 | 「经用户确认为……」「按上次口径……」 | 不进任何报告正文 |

> 与 §11.2 的区别：§11.2 禁的是**解释性散文**（讲道理），本节禁的是**过程性注记**（讲这份报告是怎么补出来的）。两者都不属于交付物内容。
> 数据有疑问的合法出口：P1 交互确认 → 专用约束登记 → 报告只写确认后的值。

### 14.2 一键自检脚本

```python
# -*- coding: utf-8 -*-
"""物理实验报告通用约束自检 —— 用法: python check.py <报告.docx> [<报告.docx> ...]
返回码 0 = 全部通过，1 = 存在不合格项。
实测：电容最终版 PASS；扭摆标准版 FAIL 2 项（页面未设 + 无 16pt 亦可通过，见下）；
      扭摆 AI 反例 FAIL 14 项。"""
import sys, re, os, zipfile

def check(path):
    x = zipfile.ZipFile(path).read('word/document.xml').decode('utf-8')
    c = lambda p: len(re.findall(p, x))
    txt = ''.join(re.findall(r'<w:t(?: [^>]*)?>(.*?)</w:t>', x))
    mtx = ''.join(re.findall(r'<m:t(?: [^>]*)?>(.*?)</m:t>', x))
    han  = len(re.findall(r'[\u4e00-\u9fff]', txt))
    body  = re.sub(r'<w:tbl>.*?</w:tbl>', '', x, flags=re.S)
    npara = len(re.findall(r'<w:p[ >]', body))
    ntbl  = c(r'<w:tbl>')
    used  = sorted({int(s) // 2 for s in re.findall(r'<w:sz w:val="(\d+)"/>', x)})
    errs  = []

    def must(ok, msg):
        if not ok:
            errs.append(msg)

    must(c(r'&amp;') == 0,                          '公式含 HTML 实体 %d 处' % c(r'&amp;'))
    must(c(r'<m:oMathPara>') >= 5,                  '显示公式段仅 %d 个（需 ≥5）' % c(r'<m:oMathPara>'))
    must(c(r'Cambria Math') > 0,                    '公式未使用 Cambria Math')
    must(c(r'tblBorders') >= ntbl,                  'tblBorders %d 处 < 表格 %d 张' % (c(r'tblBorders'), ntbl))
    must(c(r'<w:vAlign w:val="center"/>') > 0,      '单元格未垂直居中')
    must(c(r'<w:u w:val="single"/>') >= 8,          '下划线填空仅 %d 处（需 ≥8）' % c(r'<w:u w:val="single"/>'))
    must(c(r'<w:pgSz') > 0 and c(r'<w:pgMar') > 0,  '页面未显式设置 sectPr')
    must(c(r'SimSun') == 0,                         '出现 SimSun %d 处' % c(r'SimSun'))
    must(han <= 600,                                '汉字 %d 超硬上限 600' % han)
    must(npara <= 65,                               '正文段 %d 超上限 65' % npara)
    must('注：' not in txt and '注:' not in txt,      '出现「注：」段')
    must('误差来源分析' not in txt,                   '出现「误差来源分析」节')
    must(not re.search(r'u[_A-Z]\b|uA=|uB=', txt),  '出现 A/B 类不确定度符号')
    must('∑' not in mtx,                             '公式内出现 ∑（转换器会写反上下标）')
    must(not re.search(r'[&\\{}^_]', mtx),           '公式内残留 & \\ { } ^ _ 字符')
    bad = [s for s in used if s not in (12, 14, 15, 16, 18, 22)]
    must(not bad,                                    '出现非标准字号 %s pt' % bad)

    kb = round(os.path.getsize(path) / 1024)
    print('== %s  %d KB' % (os.path.basename(path), kb))
    print('   汉字 %d / 正文段 %d / 表 %d / 节点 %d / 显示公式 %d / 字号 %s'
          % (han, npara, ntbl, npara + ntbl, c(r'<m:oMathPara>'), used))
    if errs:
        print('   [FAIL]')
        for e in errs:
            print('      -', e)
    else:
        print('   [PASS]')
    return not errs

if __name__ == '__main__':
    results = [check(p) for p in sys.argv[1:]]
    sys.exit(0 if all(results) else 1)
```

| 扭摆标准版 | FAIL 1 项 | 页面未显式设置 sectPr（16 pt 结果公式已列入白名单，不报） |
| 参考格式模板 | FAIL 3 项 | 汉字 772、正文段 69、字号含 10 pt（另一门实验的体量，非本目录口径） |
| 扭摆 AI 反例 | **FAIL 14 项** | HTML 实体 15 / 无显示公式 / 无 Cambria Math / 无框线 / 无 vAlign / 无下划线 / 无 sectPr / SimSun 348 / 汉字 1645 / 段 83 / 「注：」段 / 「误差来源分析」节 / ∑ 结构 / 字符残留 |

> 脚本只做**结构化拦截**，不能替代目视。凡是脚本 PASS 但导出 PDF 有折行、孤立标题、表格跨页断裂的，仍然不合格。
> 另：脚本驱动必须写成 `results = [check(p) for p in sys.argv[1:]]`，**不能**写 `all(check(p) for p in ...)`——生成器短路会让后面的文件根本不检查（本轮踩过这个坑）。
