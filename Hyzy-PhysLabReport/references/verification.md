# P5 验收口径与自检指标

> 只跑 XML 检查不算验收。**导出 PDF 逐页目视 + 结构化自检**，两者都过才算 P5 完成。

## 一、导出（Word COM，必须走 PowerShell）

`win32com` 在本机默认 Python 环境未安装，用 `scripts/export_pdf.ps1`（**写文件时必须 `encoding='utf-8-sig'`**，否则中文路径被 GBK 解码成乱码，报"找不到您的文件"）。

```powershell
$doc = $word.Documents.Open($src, $false, $true)   # 只读打开，避免改动源文件
$doc.ExportAsFixedFormat($pdf, 17)                  # 17 = PDF
```

渲染：`pymupdf` → `page.get_pixmap(dpi=130).save(...)`，逐页看。
定位问题用 `page.get_text('blocks')` 拿每块 y 坐标：**正文最低点应落在 24.6–26.6 cm**；小于 20 cm 说明该页有半页空白。

## 二、目视清单（六条，逐页过）

- [ ] 图片完整、未被页边距裁切（重点看首行图片的顶部）
- [ ] 公式未跨行断裂、未与正文挤压
- [ ] 标题未孤立在页底（`keepNext` 生效）
- [ ] 无半页空白（表/图分页策略合理）
- [ ] 表头未溢出单元格（`U₂ = 1000 V`、`0.1057 mm/mA` 这类长串）
- [ ] 图题在图**上方**且紧跟

## 三、结构化自检指标

| 指标 | 判据 | 取数方式 |
|---|---|---|
| 汉字 | ≤ 专用上限（默认 600） | `len(re.findall(r'[\u4e00-\u9fff]', 所有 w:t))` |
| 字体 | `SimSun` = 0，`宋体` > 0 | 字符串计数 |
| 字号集合 | ⊂ {12,14,15,16,18,22} | `<w:sz w:val>` ÷ 2 |
| 显示公式 | 5–14（按**表外独占段**） | 见下 |
| 表格 | = 专用约束张数 | `x.count('<w:tbl>')` |
| 图片 | = 原始图 + 曲线图 | `x.count('<pic:pic')` |
| 习题 | = 内容要求题数 | `三、课后习题` 之后的 `N、` 标题 |
| 公式残渣 | `m:t` 内无 `& \ { } ^ _`，无 `∑` | 正则 |
| HTML 实体 | `<m:t>` 内无 `&amp;` | 正则 |
| 转义泄漏 | 无 `&lt;w:` | 断言 |
| 关键数值 | 各斜率/比值都在文档里出现 | 逐个 `in txt or mtx` |
| 符号一致 | 无旧符号残留（如应写 `U₂` 却出现 `V₂`） | 子串检查 |

## 四、显示公式计数（关键口径）

直接数 `<m:oMathPara>` 会被 Word 重存污染：**表头/表内的行内公式会被提级为 `oMathPara`**（实测 6 → 21）。正确做法：

```python
body  = re.sub(r'<w:tbl>.*?</w:tbl>', '', x, flags=re.S)   # 先剔表
paras = re.findall(r'<w:p(?:\s[^>]*)?>.*?</w:p>', body, re.S)
ndisp = len([q for q in paras
             if '<m:oMathPara>' in q
             and not re.sub(r'\s', '', ''.join(re.findall(r'<w:t(?: [^>]*)?>(.*?)</w:t>', q)))])
```

即「**剔表后、正文为空、只含 oMathPara 的段落**」。两版（AI 稿 / Word 重存稿）在此口径下都稳定为 6。

## 五、另外两个"重存假象"

| 现象 | 原因 | 处理 |
|---|---|---|
| 下划线填空 run 数从 14 掉到 5 | Word 合并相邻同格式 run | 阈值放宽为 ≥4，并检查填空内容非空 |
| 段落数 39→44、`宋体` 计数上涨 | Word 重排 XML | 只比对"汉字/表/图/字号"，不比字节 |

## 六、判定与话术

| 结果 | 话术 |
|---|---|
| 全过 | "自检 PASS（贴原文统计）+ PDF N 页逐页目视无异常" |
| 个别超限 | "X 项未达标：…；已改/待改…"，**不要含糊说"基本符合"** |
| 只跑了结构检查 | "仅结构校验通过，未做目视"——不得称"验收完成" |

> 证据先于断言：没跑过命令就不能说"已通过"；跑过要把退出码与统计原文贴出来。
