# 网页 HTML 源码 → Markdown

来源：`2026-08-26.md`（知识星球文章 HTML 转换）。

## 步骤
1. **去重**：知识星球等编辑器常把同一正文渲染多份（如 `.content.ql-editor` 与 `milkdown-preview` / `tiptap-preview`）。先定位**唯一正文容器**，只取一份，丢弃重复副本。
2. **提取正文**：取正文容器 innerText / 结构化解析，保留标题层级与表格。
3. **图片本地化**：
   - 远程图（如 `article-images.zsxq.com/...`、`mmbiz.qpic.cn/...`）用 `curl -o ./images/<语义名>.png <url>` 下载（token 到期前本地化更耐久）。
   - `alt` 多为「图片.png」等无意义值，按**所在章节语义**重命名（如 `cover`/`s1-账号总览`/`s2-搜索关键词`）。
   - 正文用相对路径 `./images/<语义名>.png` 引用。
4. **保留原文链接**：`<a href="...">` 转为 markdown 链接，原样保留（含 `http://SKILL.md` 这类原文链接）。
5. **结构**：按原文一~八 + 引言/结语/关于 建立层级；表格化处做表格；代码块（如 SKILL.md 模板）用**四反引号**防嵌套。

## 注意
- 远程图 `curl` 属**下载到本地**，不是外发材料，不违反「不外发」边界。
- 下载失败（token 过期/防盗链）时保留原 URL 并标注，不静默丢弃。
