# 结构化骨架（可复用模板）

来源：实战中反复出现的文章类型。遇到对应类型时，**先套骨架再填内容**，可显著降低结构化耗时（T2）与返工率，也避免每次重新设计层级。

> 用法：在 SKILL.md 工作流第 2 步，按输入类型选对应骨架，一次性 Write 成品。复制体/长文类用 LLM 直接写，不写解析脚本。

---

## A. 词条 / 词表型（如「24 个词讲清网页需求」「X 个 Prompt 模板」）

- 顶部：1 句定位 + 假设场景（可选）
- 底层规则段（可选，不占词条名额）
- 按「层」分 H2，如：一、布局 / 二、页面结构 / 三、导航 / 四、交互组件
- 每层下列词条，每条固定 5 段：
  - **改变什么**：
  - **何时选择**：
  - **何时别选**：
  - **推荐组合**：
  - 可复制提示词：`在 [内容区] 使用 X ...`
- 末尾配套：选择表（层级 / 词条 / 需决定的问题 / 明确排除 / 验收方式）、通用模板、示例、验收结果表。

## B. 教程 / 步骤型（多数历史任务：搭建设置、工具使用）

- H1 主题
- 概述（背景 + 目标读者 + 前置条件）
- 准备（目录 / 工具 / 素材）
- 步骤 H2（每步：操作说明 + 关键提示词/命令 + 预期结果）
- 验证 / 排错 H2
- 小结 H2

## C. 复盘 / 实战型（副本6、新岛实战、直播总结）

- 顶部 AI 摘要（3-5 句）
- 按阶段 H2（课前预热 / 核心逻辑 / 发布复盘 / 答疑 …）
- 每阶段下 H3 要点
- 末尾：可复用经验 / 决策树

## D. 逐字稿型（.txt 直播/会议）

- 顶部 AI 纪要摘要
- 按主题 H2 + H3（**禁扁平「每 4 句一段」**）
- 关键决策 / 待办用表格或列表收口

---

## 通用占位约定（与 SKILL.md 一致）

- 缺图唯一写法：`> [!note] 原文此处有配图但未随文本提供`
- 飞书「暂时无法展示」：表格类→展开 Markdown 表；音视频/文件→可点击链接；无法归类→按缺图处理。
- 图片统一 `./images/<语义名>`，附件统一 `./attachments/`。
